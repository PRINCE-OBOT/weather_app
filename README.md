# Weather App

A Weather App built as part of [The Odin Project Weather App Project](https://www.theodinproject.com/lessons/node-path-javascript-weather-app) curriculum to practice working with APIs, asynchronous JavaScript, and dynamic UI rendering.

---

## Features

* Search weather by city name
* Fetch real-time weather data from an external API
* Display temperature and weather conditions
* Dynamic weather information updates
* Error handling for invalid locations
* Responsive and interactive UI
* Loading state handling during API requests

---

## Tech Stack

* JavaScript
* HTML
* CSS
* Webpack
* Weather API from Visual Crossing

---

## What I Learned

* Fetching data from APIs
* Working with asynchronous JavaScript (`async/await`)
* Handling promises and errors
* Parsing JSON data
* Managing loading and error states
* Structuring frontend applications

---

## Challenges

* Handling asynchronous data flow properly
* Managing API errors gracefully
* Updating the UI based on fetched data
